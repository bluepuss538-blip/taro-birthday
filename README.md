# Taro birthday experience

A static, responsive birthday website designed for GitHub Pages.

## Local preview

Run a static server from this folder:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages

Publish the contents of this folder to a GitHub repository and enable Pages from the repository's default branch at `/ (root)`.

## Important privacy note

The `0605` keypad is a themed reveal, not encryption. Files committed to a public GitHub repository—including the secret video—can be downloaded by anyone who knows the repository or page URL.
